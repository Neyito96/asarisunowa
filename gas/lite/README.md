# GAS 軽量版（朝リスの輪 プレイリスト投稿受付）— 引っ越し先に入れる用

**自動生成。手で直さない。** 直すときは `scripts/google-apps-script/`（本番の控え）を直して、`node scripts/build-gas-lite.mjs` で作り直す。
`node scripts/build-gas-lite.mjs --check` と `tests/gas-lite.test.mjs` が、作り直し忘れと中身のずれを見張る。

## なにをしたか（2026-11-27）
- 本番の控え 67 ファイル・約 14,800 行 → **9 ファイル・約 11,000 行**
- 使っていない宣言（約 100 個。診断・試験・一回きりの関数など）を外し、役目ごとに並べ直しただけ。**関数の中身は 1 文字も変えていない**
- 「使っている」の入口 = 本番の時計（2026-11-27 マイトリガー画面）・Webアプリ（doGet/doPost）・シート編集（onEdit）・人が手で押す運用の関数（スイッチ、時計の設置、Spotify 認証、承認、復旧）。一覧は `scripts/build-gas-lite.mjs` の ROOTS

## 見つかったこと
- `ApiCommon.js` は同じ関数が2回ずつ書かれていて、2回目の `normalizeUrl` の途中に、別の関数（佐藤陽さんの一回きりの立ち上げ）が貼り込まれている。Apps Script では後ろの定義が勝ち、貼り込まれた部分は実行されないので、**今の動きに害はない**。軽量版も同じ形のまま残した（動きを変えないため）。直すなら、引っ越しが済んでから

## 使い方（引っ越しのとき・管理人の承認後）
1. 新しいアカウントで、新しい Apps Script プロジェクトを作る（または持ち主を移したプロジェクトの中身を入れ替える）
2. この 9 ファイルと appsscript.json を、**番号の順に**入れる
3. スクリプトプロパティ（鍵）を設定し直し、`startSpotifyUserAuth` で Spotify の認証、`installAutoUpdateAutomationTriggersV1` などで時計を設置
4. 注意: **今の本番には入れない**。配達係は本番にしかないファイルを残すので、古いファイルと二重になって動かなくなる
