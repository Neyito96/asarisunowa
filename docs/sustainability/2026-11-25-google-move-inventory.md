## 段取り（案）
1. 専用アカウントを作る（管理人）。2段階認証、予備コードは2〜3人で分け持つ。
   - **2026-11-26 済**: 専用アカウント「朝リスの輪」を作成。再設定用の電話・メールを登録し、管理人の個人アカウントを「アカウント復元用の連絡先」に設定。自撮り動画（顔での復元）は登録しない（一人の顔に縛られるため）。仲間が増えたら、その人も復元用の連絡先に足す。2段階認証はこれから。
2. 上の表を実物で確認する（Drive の「自分がオーナー」＋ Apps Script のプロジェクト一覧＋各トリガー）。
3. 専用アカウントを**編集者として共有**する（何も止まらない）。
4. 台帳から1つずつ**所有権を譲渡**する。GAS は譲渡のあと、専用アカウントでトリガーを設置し直し、旧トリガーを消す。
5. Webアプリ（投稿受付）は URL が変わらないよう、デプロイを編集して新しい版にする。動作を確かめてから次へ。
6. 全部移ったら、個人アカウントは「編集者」に下がる。
7. **引っ越しのあとで**: 専用アカウントに Google の「デジタル遺産（アカウント無効化管理ツール）」を設定（3か月・受取人にドライブを共有）。GitHub は Organization のオーナーを2〜3人にする（個人アカウントの「後継者」設定は使わない）。

> 2026-11-26 管理人判断: デジタル遺産は個人アカウントでは設定しない（ドライブ全体が渡ってしまうため）。専用アカウントへ引っ越したあとに設定する。

## 引っ越しのとき、やり直すこと・やり直さなくてよいこと（2026-11-25 追記）
**そのまま**
- GitHub の鍵（fine-grained token「asarisu-sync-kicker」、期限 2027-11-25）… GitHub アカウントのもの。Google の引っ越しとは無関係
- GAS のコードとスクリプトプロパティ … 所有権の譲渡なら残る見込み（移したあとに確認）

**やり直す**
- トリガー … 設置した人の権限で動く。新アカウントで設置し直し、旧アカウントのものは消す
  - 配達係: `DELIVERY_INSTALL_HOURLY`、`K2_トリガー設置`（旧は `K9_トリガー削除`）
  - 本番GAS・清掃ロボ・本番ロボGAS（6:41）: 各トリガー（実物で一覧を確認してから）
- 許可（OAuth の同意）… 新アカウントで初回実行時に押し直す
- Google Cloud（asarisunowa-delivery）… 新アカウントをオーナーに追加（作り直さない）
- 投稿受付 Webアプリ … 新アカウントで「デプロイを管理」→ 編集 → 新バージョン（URL を変えない）

**GitHub を Organization に移すとき**
- 鍵「asarisu-sync-kicker」は Neyito96 の持ち物だけに効くので、Organization を持ち主にして作り直し、配達係の GITHUB_TOKEN を差し替える（Organization 側で fine-grained token の許可が要る場合あり）

**1つ移すたびに**: トリガーを設置し直す → 運行状況（/status/）が緑か確かめる → 次へ
