# 登録＋自動更新 一括申請

## 目的

朝リストへ新規登録するSpotifyプレイリストについて、同じ入力内容を使って自動更新申請も続けて送れるようにする。

## 動作

1. 通常の `kind: "playlist"` を送信
2. 同じURL・タイトル・朝リスネームを使って `kind: "autoUpdateRequest"` を送信
3. Spotifyへの直接書き込みは行わない
4. 自動更新は従来どおり管理者確認後に設定する

## 対象

- Spotifyプレイリストのみ
- YouTube Musicは通常登録のみ

## 安全性

- 既存の合言葉を使用
- honeypot項目を維持
- GAS、Spotify API、スプレッドシート構成は変更しない
- 1件目だけ送信できて2件目が失敗した場合は、登録済みプレイリスト向け申請フォームへ誘導する
