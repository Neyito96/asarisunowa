# SDGs公式JSONのGAS読み取り専用検証

このファイルは既存の本番GASには組み込まない。独立したApps Scriptプロジェクトに `tools/sdgs_official_archive_gas.gs` を貼り、`SDGS_previewOfficialArchive()` を手動実行する。

- 公式JSONの1〜3ページを取得し、件数・UUID重複・HTTP応答をログ出力する。
- 公式個別ページURLはUUIDから**生成**するだけで、リンク先の実在は確認しない。
- Omnyの埋め込みURLは音声ファイルURLとみなさない。
- 書き込み・トリガー作成・プロパティ変更を行わない。
- 429/503、空ページ、JSONスキーマ不一致の場合は停止または例外とし、成功と誤認しない。
- 1007コピーの既存M列に値がある場合、URL形式が異なるだけで上書きしない。
