# 2026-10-26｜切替方針訂正：COPYロボを保険として継続

先の「本番移行の最初にCOPYの時間トリガーを停止」は撤回。実績のあるCOPYを、未検証の本番ロボのために停止しない。

## 合意した安全な順序
1. COPY側のトリガーとCOPY台帳への自動収蔵は当面維持する。削除・停止しない。
2. 本番側はREAD_ONLYのシャドー検証を進め、実際の新着取得、GUID照合、V4整形、採番候補、登録後の整合性を比較する。
3. COPYと本番の同一GUIDのEP-IDの重複/不一致を逐次照合する。別台帳の採番結果を独立の正本として扱わない。
4. 本番の限定登録実験はデータ・状態・採番履歴・再実行の安全性を確保してから進める。新着の二重書き込み禁止。
5. 本番トリガーが実際に複数回安定運転できることを検証し、その後に採番権限の切替を判断する。最終切替点でのみCOPYの独立採番停止または監査専用化を検討する。COPYの台帳とプロジェクトは保存する。
