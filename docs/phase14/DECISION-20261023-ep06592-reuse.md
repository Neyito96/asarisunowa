# Phase 14｜最優先・開発方針（2026-10-23）

## ユーザーの確定指示
**2026年10月23日にEP-06592を正式登録できた成功手法を、今後の「新着エピソード自動収蔵」と「既存台帳の空欄補完」の両方に共通する標準方式として再利用する。**

成功実績とPR #251を出発点にし、別エンジンをゼロから作り直さない。既存コード・GAS・公式RSS・Omny公式JSON・検証手順を再利用し、GAS時間トリガーによる安全な無人巡回を完成させる。10件ずつの手動試験を繰り返すことは目的ではない。

### A｜新着エピソード
公式RSS検出 → Omny公式JSONとの照合 → GUID/UUID重複検査 → EP-ID採番 → 台帳への安全な登録 → 概要・出演者・関連記事・音声・外部再生リンクの補完 → 記録・再読込検証。重複登録と並行処理競合を防ぐ。

### B｜既存エピソード
既存EP-IDを起点に、Aと同じ照合・情報抽出・検証ロジックで空欄のみ補完。既存の値、EP-ID、GUID、音声URLは原則不変。不確実な候補は保留し推測で埋めない。途中停止後の安全な再開と失敗行の記録・再試行を設計する。

- EP-06592「（PUERTA #25）不正アクセス急増　AIに委ねるか滅ぼされるか　2040への分岐点」はユーザーと共同で2026-10-23に正式登録した成果。第三者の不明な処理による追加として扱わない。

- 実台帳・GAS・トリガーの変更は個別の安全確認とユーザーの明示承認が必要。開発ブランチへの作業は継続可。
