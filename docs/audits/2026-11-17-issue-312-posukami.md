## 追加（11:17 管理人ネジートの提案）「ポすすめ返し」回（11:23 名前を決定。仮称は「ポすすめ振り返り」）
ポすすめで紹介されたあと、紹介された番組が自分の番組で振り返った回を、同じカードに載せる。

**しくみ**（ポす神回と同じ流れ。コミット `eb8a656`）
- 投稿の種類に `reply`（ポすすめを受けて、この番組が配信した振り返り回）を追加した。
  - 配信者本人も、ほかのリスナーも、同じ「教える」ボタンから送れる。
  - 確かめ方（回のURLか・二重投稿でないか・番組ID＋番組名の一致）と、承認キューはポす神回と同じ。
  - 関係の手がかりに、2つを追加した。
    - ページに「ポすすめ／日曜版／ドーナツ」があるか
    - 紹介日以降の配信か（紹介日より前なら「要確認」と記録）
- カードでは「💬 ポすすめ返し」の別欄に載せる。並びは「🎙 紹介された回 → 💬 ポすすめ返し → ✨ ポす神回」。
  - 公開データには `replies` を足した。古いデータに `replies` が無くても壊れない。
- 候補を自動で探す仕組みも作った（`POSU_C6_振り返り候補_READ_ONLY`、読むだけ・自動では載せない）。
  - Apple 公式の iTunes Search API で、各番組の新しい50回を1回ずつ読む。
  - 「紹介日から90日以内」かつ「ポすすめ／朝日新聞／朝ポキ／ドーナツ／神田」への言及がある回を候補にする。題名で言及していれば強い候補。

**実測**（COPY「ポす・振り返り候補」）
- 対象20番組のうち、Apple の番組IDが分かったのは18番組。候補が見つかったのは6番組。
- 候補は、強い候補7件・弱い候補12件。
- 強い候補の例
  - ネジネジ低空飛行「#34 ぽすすめ　朝日新聞に載った日…」（10/25）
  - 奥会津、風のラジオ「#25 [番外編]ポすすめ返し、ポすすめ送り」（9/19）
  - おんすた「最近の出来事・朝日新聞ポッドキャストで紹介いただきました。＃49」（10/25）
  - クリエイティブの反対語「#407 朝ポキで紹介してもらった！！」（10/25）
  - ながらcast「191『ドーナツ』@朝日新聞ポッドキャストの『ポすすめ』で…」（11/11）
- 誤検出もある。
  - おんすたの「過去回・本咄『朝日新聞政治部』」は、本の名前に反応しただけ。
  - #410 は振り返り回ではなく、ポす神回（神田さん出演）。
  - だから候補は自動では載せず、投稿と承認を通す。
- 呼び名の参考: 番組側が「ポすすめ返し」という言葉を使っている（奥会津、風のラジオ #25）。
