## 第3課題　ポッドキャスト茶会（PODCAST 19）の Spotify 欠落
- **原因はデータです**: `朝リスPodcast` の該当行（21行目、紹介配信日 2026-11-03）の **Spotify 列（F）が空** です。画面のコードは、値がある時だけボタンを出すので正しく動いています。
- **もう1つの不具合**: 同じ行の **LISTEN 列（H）に RSS の URL**（`https://rss.listen.style/p/podthakai/rss`）が入っています。番組URL（A）と RSS（N）も同じ値です。そのため「LISTEN」ボタンを押すと、番組ページではなく RSS ファイルが開きます。
- **直し方**: 本番のスプレッドシートなので、**管理人の承認が必要** です。
  - 承認後、F21 に既知の番組URL `https://open.spotify.com/show/7dDe6pPYCdUUDQ2AL40xtE` を入れる。
  - H21 を LISTEN の番組ページにする。`https://listen.style/p/podthakai` になるはずですが、Claude はまだページを開いて確認していないので、**入れる前に確認** が必要です。
  - 入れれば、リスナー番組の欄はページを開くたびにシートを読むので、デプロイなしで反映されます。
  - Spotify の番組URLが有効かどうかも、Claude in Chrome が切れたため **未確認** です。
- **補完器（PR #276）**: タイトル検索の失敗理由を分けて記録するようになりましたが、既知のURLがある時は、検索より確定値を優先する方が確実です。
- **他の番組**:
  - 「LISTEN はあるのに Spotify が無い」番組は、この1件だけです（全20件を確認）。
  - Spotify 列に `x.gd` の短縮URLが入っている番組が4件あります（歴史から学ぶ精神科ラジオ・注文の多い出版相談室・うんちく聖書ラジオ・ののラジオ）。リンク先が Spotify かどうかは未確認です。
