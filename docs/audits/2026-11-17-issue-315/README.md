## 4. 共有カード・共有URL

- 「共有の準備へ」→ プレビュー（回ごとにチェックで外せる）→「共有URLを作る」→ コピー。
- URLは `library/#s=1.<base64url>`。中身は `{t:タイトル, d:説明, i:[EP番号]}` だけ。名前・メール・検索語・端末ID・秘密情報は入らない。`#` 以降なのでサーバーにも送られない。
- 受け取った人はアカウントなしで見られる。カードは 番組名・エピソード名・配信日・蔵の個別ページ・配信リンク。
- 配信リンクは **蔵の公開データにある既知の配信先だけ**（Spotify / Apple / Amazon Music / Pocket Casts / LISTEN / Pody / YouTube / 朝日新聞 / Omny 公式ページ）。音声ファイル直リンク・不明なサイト・http は出さない。P27 の未検証・HOLD の URL は V2 に書き込まれていない（`P27_V2_WRITE_ENABLED_=false`）ので混ざらない。
- 公開されていない回・削除された回は「この回は現在、蔵で公開されていません」とだけ出す（タイトル等は出ない）。壊れたURLは何も出さない。
- 受け取った側の端末には自動で保存しない。「この一覧を自分の蔵書一覧に入れる」を押したときだけ保存。

### URLだけ方式 と サーバー保存方式

| | URLだけ（採用） | サーバー保存 |
|---|---|---|
| 新しい外部DB | 不要 | 必要（無断導入は禁止） |
| 個人情報 | 何も預からない | 一覧を預かる |
| 取り消し・期限 | **できない**（URLを知る人は見続けられる） | できる |
| 後から中身を変える | できない（新しいURLを作る） | できる |
| URLの長さ | 50件で約400字 | 短い |

取り消しできないことは共有画面に明記した。削除・期限: 端末側は「この端末から一覧を消す」で即削除。共有URLはサーバーに無いので期限なし・消去不可。
