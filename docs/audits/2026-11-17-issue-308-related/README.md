# #308 蔵の関連記事：見出し＋URL＋QR（2026-11-17）
- **原因**: 蔵のデータの関連記事が URL だけだったため、どれも「朝日新聞 公式ページ ↗」と表示されていた。旧V1の書き出しで記事URLが入らなかった回も多い。
- **見出しの出どころ**: V2・清掃詳細の「関連記事JSON(見出し+URL)」。SC4-18 が公式の原文から取り出したもので、URLの取りこぼし0を監査済み（#308 SC4-18）。
  - COPY清掃ロボの `RelatedExport.gs`（RX-1）が、公開対象の回だけを読み出して返す。V2は読むだけで、どこにも書かない。
  - GitHub Actions（`library-related-titles.yml`）がこれを読み、`apply-related-titles.mjs` で蔵のデータを作り直す。Claude は全件を読んでいない。
- **結果**: 公開6,075件のうち、5,049件の関連記事 13,396件に見出しが付いた。見出しが無い記事は145件で、URLのまま「記事（見出し未確認）」と表示する。
  - 関連記事が空だった4,318件は、V2の見出し＋URLで埋めた。URLを推測で作ることはしていない。
- **表示**: 見出しをリンクにし、その下にURLを表示する。パソコンでは「QRコード」ボタンを押すと、ブラウザの中で QR を作る（記事URLを外部サービスに送らない）。スマホには QR ボタンを出さない。
- **検証**
  - QR生成器の型番3〜9を OpenCV で読み取り、全一致。画面のスクリーンショットの QR も正しく読み取れた。
  - 単体テスト 4件合格。ブラウザ試験（パソコン・iPhone 13）合格。既存の蔵の試験（蔵書一覧・共有・検索）も合格。
- 画面: `related-pc.png`（パソコン・QRを開いた状態）、`related-sp.png`（スマホ）
