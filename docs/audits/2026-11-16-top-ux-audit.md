## 1. 現行トップページのUX診断（実機で観察した事実）
| 重要度 | 問題 | 根拠（観察） |
|---|---|---|
| 高 | 報談カードの「公式」がリンク切れ | omny.fm/shows/asahi/playlists/playlist-1 を開くと「プレイリストは利用できません」（Chrome、2026-11-16）。他の Omny 公式ページ（ドーナツ・スポンジ・MEDIA TALK・ニュースの現場から・こどもそうだんしつ・ニュースの学校・アルキキ/AJW）は番組名のページが開いた |
| 高 | 朝公式の見出しが「OFFICIAL PLAYLISTS／朝日新聞ポッドキャストの公式プレイリストです」（PCは「朝公式プレイリスト」） | 番組（ショー）をプレイリストと呼んでおり、連載・朝リストの Spotify プレイリストと紛れる |
| 高 | 連載・朝リストが Spotify のプレイリストだと、タブや見出しでは分からない | 「Spotify」が出るのは各カード下の「Spotifyで聴く」と注記「楽育ち＝現在はSpotifyで自動巡回中」だけ |
| 中 | 「連載」が朝日新聞の公式連載（asahi.com の ?pgid=…）と同じ言葉 | リスナー制作の棚（by 田田田 など）が公式連載に見える |
| 中 | 番組カードの「公式 ↗」がどこへ行くか分からない | 行き先は Omny（朝日新聞ポッドキャストの配信ページ）だが、ラベルは「公式」だけ |
| 中 | タブに role="tab"／aria-selected が無い | tablist の中のボタンが選択状態を読み上げに伝えない |
| 低 | こどもそうだんしつの Amazon Music リンクが旧番組名（SDGsを話そう アーカイブ）の es-us ページ | URLの表記から。開いた先は未確認 |
| 低 | スポンジの Pocket Casts が短縮URL（buff.ly） | 行き先が見えない。開いた先は未確認 |
「朝リスの田」が非公式であることは、上部の「非公式・リスナー制作｜情報は最新・正確でない場合があります」で常時表示されている（良い点）。

## 2〜3. 改善（コード・テスト済み、未公開）
- 番組カードの「公式」→ 赤い「公式」バッジ＋「配信ページ ↗」（Omny）／「公式サイト ↗」（asahi.com）。スマホでも常時表示。PCはツールチップ「朝日新聞ポッドキャストの公式配信ページ（Omny）を別タブで開きます」。読み上げ名は「番組名：…（別タブで開く）」。ラベルはリンク先の属性だけで、朝リスの田を公式に見せない
- 報談の「公式」→ 利用できない Omny ページをやめ、朝日新聞ポッドキャスト公式トップへ（正しい番組ページが確認できたら差し替え。URLは作らない）
- 朝公式の見出し → 「OFFICIAL SHOWS／朝日新聞ポッドキャスト 公式番組」「ボタンから各サービスの番組ページへ移動します」
- タブ「連載」「朝リスト」に小さく「Spotify」（スマホは2行目、PCは横）。読み上げ名「連載（Spotifyのプレイリスト）」。タブの文字数は増やしていない
- 連載・朝リストの棚の説明に「Spotify専用」: リスナーが作った Spotify のプレイリストで、朝日新聞の公式ページではない／Spotify のアプリかウェブで開く／保存・フォローには Spotify のアカウントが要る／Spotify 以外は「朝公式」の番組ページから
- 「連載＝番組の中のシリーズを追いかけるリスト」に言い換え
- 全タブに role="tab"・aria-selected、キーボードのフォーカス枠
- 既存機能（登録・自動更新・おみくじ・既聴管理・並べ替え）のコードは触っていない

## 4. 将来の蔵連携（設計のみ・未実装）
- 共通キーは EP-ID。個別ページで「公式（公式GUID/UUIDの個別ページ）→ 確認済みのサービス → 照合済みのサービス」の順に出し、未確認・未取得のサービスは出さない（URLを作らない）
- 現在の取得状況（V2 6,597行）: Spotify 6,544（照合）／Apple 751、うち739は Apple公式APIのGUIDで確認、新規350件は COPY に候補／Pocket Casts 6,531（開く確認は未）／LISTEN 3,918（照合）／Amazon・Pody・YouTube 0
- 再配信で重複除外された回は、代表の元配信のページへ案内（docs/operations/2026-11-16-rebroadcast-policy.md）。件数は docs/audits/2026-11-16-net-count.md の正味 6,101件（6,597件は監査の母数。AJW・アルキキ・YouTube動画は含めない）
- Spotify のプレイリスト（朝リスト・連載）は蔵のエピソード一覧とは別の棚として、個別ページに「この回が入っているSpotifyプレイリスト」と分けて出す
