## 照合ルール（番組名だけ・タイトルだけでは確定しない）
強キー = 朝日公式 itemid（外部M ↔ 台帳J/外部ID）、Omny URLスラッグ（外部A ↔ 台帳I）、Spotify/Pocket Casts のエピソードID一致。
- **確定一致**: 強キーが台帳の1行だけを指し、日付が1日以内、外部原本内に重複なし。
- **曖昧**: 強キー無し、タイトル+配信日のみ一致 → 保留。
- **競合**: 強キーが複数行を指す／日付が2日以上ずれる／外部内重複。
- **未一致**: 台帳に対応なし。
- 同じ番組名の台帳行があればそれに絞る。タブは配信フィード単位の箱なので、無ければ別番組名でも強キー一致を認める（`showMismatch`）。
- 補完は確定一致かつ台帳セルが空のときのみ。台帳に値があって違えば `URL_CONFLICT`（上書きしない）、Omnyフィードが違う場合は `URL_CONFLICT_FEED`。
