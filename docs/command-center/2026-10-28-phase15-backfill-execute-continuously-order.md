# Phase15｜補填を止めずに進める実行指令（2026-10-28）

## 司令塔の判断
COPY専用試験タブへの5行・30セルの模擬追記（見出し込み36セル）は確認報告として受入。ただしこれを本番補填実績として数えない。ユーザーの最優先は **本番エピソード台帳の空欄を実際に埋め、継続自動化すること**。設計書のみの往復を終了する。

## 優先1｜今すぐ補填を実行する
- 既に本番登録済み EP-06633〜EP-06640 の8件について公式RSS・公式JSONから照合済みの空欄データを取得する。GUID一致を原則とし、同一性不明はスキップ。
- 対象列は実見出しに合わせる：概要原文、概要清掃済み、音声URL、画像URL、再生時間、所属ID、出演者と根拠、公式個別URL・配信先リンク、収集日時・取得元等。公式データから確実な値だけ。既存の手入力値には触れず、**空欄のみ更新**。
- まずCOPYで数件・複数列の実補填を行い、再実行で追加更新0セル、元値保持を検証。その結果を提示し、直後に本番へ反映する具体的な更新セル一覧と実行手順を提出する。許可された本番書込は実施して更新セル数を報告する。
- ユーザーが既に実行優先を明言している。曖昧な全般監査を理由に停止しない。未完成の項目だけ保留し、補填できる項目から処理する。

## 優先2｜継続巡回の自動化
- Phase14の既存巡回エンジンを再利用し、既存台帳の空欄補填を少数行バッチ・保存カーソル・再開位置で継続。エラー行スキップ、取得元の明示、実行履歴記録。
- 新着収蔵エンジンと補填エンジンを単一の接続先・責任範囲で管理。既存の本番トリガー/開発コードと衝突しないことを確認してから、自動実行の最小手順を提示。
- 公式RSSの最新3件だけを対象にするのは新着チェック側であり、**既存空欄補填は台帳全体を巡回する**。過去3,909件のGUID不一致調査と混同しない。
- 除外対象（AJW、アルキキ、YouTube）はスキップ。RSS・JSONから推測で値を埋めない。
