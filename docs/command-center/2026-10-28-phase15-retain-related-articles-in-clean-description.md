# Phase15｜清掃規則の訂正：関連記事を清掃済み概要に保存（2026-10-28）

ユーザーの本番6件の確認結果に基づく優先指令。従来の「【関連記事】以降を全削除」は撤回。

## 正式なW列仕様
- W列「概要清掃済み」には、エピソード固有の説明本文、必要な収録日、**【関連記事】見出し、関連記事のタイトル、対応するURL** を原文順で残す。
- 関連記事は1記事につきタイトルとURLが対応する状態で、実際の改行（LF）を保存。リンクのクエリ文字列も原文のまま保全し、HTMLエンティティは読み取れる表現へ復号。
- 出演者一覧、定型の【おねがい】【朝ポキ情報】、購読・広告宣伝、Discord/SNS/メルマガ、イベント参加申込・告知や共通フッターを概要から除外する。**記事そのもののリンクとイベントを解説する本題は削除しない**。
- 原文V列は一切変更しない。V空欄なら公式RSS/JSONをGUID一致で取得して補填してからW生成。
- 既存の関連記事URL列（AC）はWと並行して使ってよいが、**ACへ保存したことを理由にWから関連記事見出し・タイトル・URLを消さない**。

## すでに本番に書いた6件の是正
対象：EP-00001、00002、00003、00021、00022、00023。
- 現Wは以前の誤ルールで生成されたため品質修正の対象。元Vを基準に「本文＋必要な収録日＋関連記事（タイトル・URL）」を再生成する。
- 各行のV/GUID/Wを更新直前に再読。既存Wの現在値は退避して差分を記録したうえで、**この6件についてのみユーザーの修正指示に従ってWを置き換える**。他の既存Wは一括上書きしない。
- まずEP-00001で関連記事全3本のタイトル・URLが残ることと不要な宣伝を消せたことを検証し、次に残り5件を修正。関連記事なしのエピソードには架空の関連記事を追加しない。
- 修正後、ユーザーの目視で確認できる比較（本文・関連記事・除外部分）と実際の本番更新セル数を報告。

## スケール
この修正を清掃エンジンとテストに反映するまでは、旧ルールによる100/500/1000行の連続本番補填をしない。品質が整えば少数の例外確認のみで連続処理に移行する。改行LF、行高さ制限、原文保護は従来どおり。
