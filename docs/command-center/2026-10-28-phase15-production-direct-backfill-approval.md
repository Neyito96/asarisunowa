# Phase 15｜本番直接補填へ移行（2026-10-28）
司令塔指令。ユーザーは本番データへ書き込みながら進める方針を承認。COPYで大量に清掃→まとめて手動コピペ方式は終了。

## 実施方針
- 更新先は本番エピソード台帳のみ。既存値は上書きしない。台帳の列とGUIDと更新直前の空欄を検査。
- V列概要原文が空欄なら、公式RSS/JSONとGUID照合できた値をVへ取得。W列概要清掃済みは関連記事、イベント告知・申込、出演者一覧、宣伝や共通案内を除外し、説明本文と必要な収録日を保持。LF改行を維持。
- 既存COPYで生成したHTMLタグ除去のみの318セルは品質不合格。本番へ転記しない。
- 品質確認済みの小バッチから本番直接更新。正確性を確かめた後に100件、500件単位で連続実行。確認できない行だけ保留して次へ。
- 行高・折り返しはデータとは別に調整し、セル表示が長大にならないようにする。本文のLFはセル値の中に保存する。
- 全実行で対象EP-ID、更新列、処理済み行数、実際に書いたセル数、既存値上書き0、失敗・保留数、次回カーソルを記録。新着ロボとの同時書込競合を避ける。
- 現行既存W値の自動再清掃・一括上書きは対象外。原文と清掃が一致しない場合は保留・別レビュー。
- 初回の本番品質合格行の更新結果を提出し、以後は正常な限り連続バッチへ進める。追加の設計書のみの報告は不可。

## 実行権限
ユーザーは本番直接補填方針を明示している。厳格な空欄限定・公式根拠付きの補填を実施する。GASの新規時間トリガー設置・既存ロボ変更などは別途説明して承認を得る。
