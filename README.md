# 朝日新聞ポッドキャスト案内所「朝リスの田」

朝リスの輪（田・蔵・宇宙）は、朝日新聞ポッドキャストを聴くリスナー『朝リス🐿️』が、みんなで育むコミュニティサイトです。

公開URL: https://neyito96.github.io/asarisunowa/

## 公開しているもの・ライセンス
- コード: [MIT](LICENSE)
- 朝リスの輪が作ったデータ（EP-ID・分類・星の位置・配信先リンクの対応表など）: [CC BY 4.0](DATA-LICENSE.md)。回の題名・概要欄・音声は朝日新聞社など各権利者のもので対象外
- データの入口と使い方: https://neyito96.github.io/asarisunowa/open/

## 続けていくために
特定の個人やAIに頼らず続くサイトを目指しています（[#493](https://github.com/Neyito96/asarisunowa/issues/493)）。Google の持ち物を専用アカウントへ引っ越す一覧: [docs/sustainability](docs/sustainability/2026-11-25-google-move-inventory.md)。高額な有料AIからは早めに抜けて、手引きで回せる・みんなでつくる形にします。

## 公開方法

`main` ブランチへ更新を送ると、GitHub Actions が静的サイトを生成し、GitHub Pagesへ公開します。

♡は共有ランキングではなく、各端末のブラウザ内だけに保存される「聴いた」印です。コメント、アクセスカウンター、サーバーへの個人データ保存はありません。
