全体のこと

田・蔵・宇宙・星読みは、それぞれ何ですか？

朝リスの輪（田、蔵、宇宙）は、朝日新聞ポッドキャストを聴くリスナー『朝リス🐿️』が、見て聞いて、書いて動かして話したりしてみんなで育むコミュニティサイトです。膨大な番組と、それを毎日届けつづける朝ポキの発信力に、敬意を表して。

  • 朝リスの田（開く）… 入口です。プレイリストやおすすめなど、聴くきっかけが集まっています。
  • 朝リスの蔵（開く）… 主な8番組のこれまでの回（約6,100回）の書庫です。アルキキ・AJW・朝ポキTVはまだ入っていません。題名や出演者で探して、聴く先へ飛べます。
  • 朝リスの宇宙（開く）… 回を星にして、分類・言葉・時間・地図で眺める場所です。
  • みんなで星読み（開く）… 回が宇宙のどのあたりの星群に入るかを、朝リスのみんなで見立てる場所です。
朝日新聞社の公式サイトですか？

いいえ。朝日新聞社とは関係のない、リスナーがつくる非公式サイトです。朝日新聞社からの許諾や、提携はありません。

番組を探して、公式の配信先（Spotify・Apple Podcasts など）で聴いてもらうための案内として、番組名・回の題名・概要欄・番組画像を、出典が分かる形で表示しています。これらの権利は、朝日新聞社など各権利者にあります。

権利者の方へ：表示の訂正や削除のご要望は、朝ポキ Discord で運営者（ネジート）にお知らせいただくか、GitHub の Issue にお書きください。速やかに対応します。

意見や開発のアイデア、メモは、どこに書けばいいですか？

どなたでも歓迎です。書きやすいほうへどうぞ。

  • 気軽な感想・質問・「こうなったらいいな」 … 朝ポキ Discord へ。
  • 開発のアイデア・不具合の報告・メモ書き … GitHub の Issue（課題の掲示板） へ。読むのはだれでもできます。書くには無料の GitHub アカウントが要ります。新しく書くときは、箇条書きのメモで大丈夫です。すでにある Issue に一言コメントするのも歓迎です。

Issue は公開されます。お名前や連絡先など、個人の情報は書かないでください。

分類はだれが決めているのですか？

今の分類は、AI（Claude）が題名・概要欄などの手がかりから付けた試作です。人が確かめた回は、人の判断を優先しています。

分類の分け方や名前そのものも、まだ決まったものではありません。みんなの見立てや意見で、これから育てていきたいと思っています。

宇宙の見かた

分類のまわりにある薄い星は何ですか？「保留」の回とは？

分類がまだ決まっていない回です。AIが分類しようとしたものの、手がかりが弱くて決めきれなかった回を、以前は「保留」として1か所に集めていました。

いまは集めずに、近そうな分類のまわりに薄い星（ふちの星）として散らしています。分類と分類のあいだに、はっきりした境目は引いていません。

  • 星を選ぶと「〇〇のあたり？（まだ決まっていません）」と出ます。
  • みんなの見立てが集まると、星はその分類のほうへ少しずつ寄っていきます。
  • 手がかりがまったくない回だけ、「ミミマチ星群（仮）」として外に置いています。名前もみんなで決めたいと思っています。
  • 分類の回数には入れず、分類のページに「ふちの星 〇回」と別に出しています。

聴いた人の見立てが頼りです。みんなで星読みで、近いと思う分類を選んでもらえるとうれしいです。

1つの回が二つの分野に入っていることがあります。星は2つあるのですか？

いいえ、星はどの回も1つだけです。いちばん近い分類（主分類）の集まりの中に置いています。

ほかの分野の話題にも触れている回は、回の画面に「この回は『〇〇』の話題にも触れています」と文字で出ます。そちらの分野には星も線もありません。

回を選ぶと出てくる線は何ですか？

その回と関係のある回へ引いた線です。関係があるとみなす根拠は、次の3つだけです。

  • 金色の線 … 同じ記事を紹介している回
  • 青っぽい線 … 同じ出演者が出ている回、または共通の言葉がある回

関係のある回が別の分野にあると、線はそちらまで伸びます。分野どうしをつないでいる線ではありません。くわしい根拠は、回の画面の「関連する回（根拠つき）」に出ています。

緑色の点や線は何ですか？

点（星）の色は分類の色です（分類のまわりの薄い星は、そのあたりにある、まだ決まっていない回です）。20の分類にそれぞれ色があり、緑系は「暮らし・生活」「動物・自然」「環境・気候」「健康・医療」「福祉・介護」です。

「言葉」の表示で言葉を選ぶと、青緑の線と ◆ が出ることがあります。◆ はその言葉が見出しに入った朝日新聞の記事で、線はその記事を紹介した回へつながっています。

分類のページにある色の帯は何ですか？

その分類に入っている回が、だれが・どれくらいの手がかりで分けたかの内訳です。色ごとに、回数の割合だけの長さになっています。

  • 緑 … 人が確かめた回
  • 青 … AIが「手がかりが十分」と見た回（確度 高）
  • 黄 … 手がかりがそこそこの回（確度 中）
  • 赤 … 手がかりが少ない回（確度 低）。ほかの分類のほうが近いかもしれません

色は「正しさ」の印ではありません。人の見立てもAIの判断も、どちらもまちがえることがあります。「この回はちがうかも」と思ったら、みんなで星読みから見立てを送ってください。

みんなで星読み

何人でも参加できますか？ 選んだ分類はどうなりますか？

だれでも、登録なしで参加できます。聴いた回・気になった回だけで大丈夫です。

  • 選んだ分類は、1人目から宇宙のその回に「みんなの見立て」として表れます。
  • 自分の1票はその端末ですぐに、ほかの人の分は30分ほどで反映されます。
  • 3人以上の見立てがそろって、3分の2が同じ分類なら「みんなの分類（候補）」として目立たせます。
  • 同じ回は何度でも選び直せます。数えるのは最後の1回です。
AIがもう分類した回に、ちがう意見を送れますか？

送れます。宇宙で回を開くと「この分類、ちがうかも？ 見立てを送る →」という入口があります。そこから、いまの分類を見たうえで選べます。

「ひとこと」やニックネームは公開されますか？

公開されません。この場をよくする参考にだけ使います。公開されるのは、回ごとの分類の票の数だけです。

分類の分け方や名前を提案したいです

大歓迎です。朝ポキ Discord で聞かせてください。星読みの「ひとこと」欄に書いてもらうこともできます。

蔵書（蔵）

蔵書は、いくつも作れますか？

いまは1つの端末（ブラウザ）に1つだけです。蔵書はその端末の中にだけ保存され、サーバーには残りません。

別の蔵書を作りたいときは、「この端末から一覧を消す」で空にしてから、新しく回を入れていきます。ほかの端末やブラウザでは、それぞれ別の蔵書になります。

「URLで人に渡す」で作ったURLは、あとで蔵書を変えると変わりますか？

変わりません。URLには、作ったときの回の番号・タイトル・説明がそのまま書き込まれます。

  • あとで蔵書を作り直してURLを作ると、別のURL（別の蔵書）になります。
  • 前に渡したURLは、前の中身のまま見られます。サーバーに保存しないので、取り消すことはできません。渡す相手を選んでください。
  • URLに入るのは回の番号・タイトル・説明だけです。お名前や端末の情報は入りません。
人から受け取った蔵書を、自分の蔵書にできますか？

できます。共有URLを開くと出てくる「この蔵書をわたしの蔵書に入れる」を押すと、その回が自分の蔵書に加わります。

聴くリンク

聴くリンクはどんな順番で並んでいますか？

どの回も「朝日新聞 公式ページ → Spotify → Apple Podcasts → そのほか（Amazon Music・LISTEN など）」の順にそろえています。

プレイリストの自動更新（田）

テーマ別のプレイリストには、どんな回が入りますか？

申し込みのときに書いてもらったキーワードで、朝リスの蔵（これまでの回の書庫）の題名と概要欄を探します。見つかった回は、Spotify でも同じ番組・同じ題名の回だと確かめてから、プレイリストに足します。

探しに行くのは数時間おきです。一度に確かめる数には上限があるので、見つかった回が多いときは何回かに分けて少しずつ増えていきます。

キーワードが概要欄に出てくるだけの回も入るので、テーマから少し外れた回が混ざることがあります。そのときは、次の質問のとおり Spotify で消してください。

※ この「蔵で探す」しくみは、2026年11月24日以降に申し込まれたテーマ別プレイリストが対象です。

テーマに合わない回が入っていました。どうすればいいですか？

Spotify でその回をプレイリストから消すだけで大丈夫です。ほかの手続きはいりません。

しくみは「人が消した回だ」と気づくので、同じ回を二度と入れ直しません。残したい回は、そのまま置いておいてください。

入っていた回が、自動で消えることはありますか？

ありません。自動で行うのは回を足すことだけです。消すのは、プレイリストを管理しているあなただけです。

同じ回が2本入っていました

同じ回が番組の再配信などで別のものとして出ていると、2本入ることがありました。今は、同じ題名の回は1本だけ入れるようにしています。

すでに2本入っている場合は、Spotify でどちらか1本を消してください。消した方は戻ってきません。

これから（続けていくために）

日々のメンテ・運用は、どのくらいの負荷なのですか？

朝リスさんからいただいた質問です。ふだんの更新は、ほとんどロボット（自動の処理）がやっています。

  • 毎朝 … 新着の取り込み（6:41ごろ）、蔵と宇宙への反映、Amazon Music などの配信先リンク探し
  • 毎時〜数時間おき … プレイリストの自動更新、テーマ別の蔵探し、自動処理のコードの配達

人の手がかかるのは、本番のデータを書き換える前の確認と承認、ロボットが止まったときの直し、新しい機能づくりです。いまは、その直しと機能づくりの多くを、有料のAIの手を借りて進めています。

このままでは、費用も知識も一人とAIに偏ってしまいます。高額な有料AIからは早めに抜けて、手引きを読めば人の手で回せる形にし、朝リスのみんなでつくっていけるようにしたいと考えています。

だれかがいなくなっても、続けられますか？

「つくりはじめた人が明日いなくなっても生きていくサイト」を目指して、段取りを進めています。

  • コードとデータを開いた形で置く … 公開しているものにまとめました。コードは MIT、朝リスの輪が作ったデータは CC BY 4.0 で、だれでも引き継げます。
  • 持ち主を個人から「朝リスの輪」へ … Google（台帳・自動処理）を専用アカウントへ引っ越し、GitHub も「輪」の持ち物にする予定です。
  • 鍵は2〜3人で分け持つ … 一人が欠けても開けられ、一人では勝手に変えられない形に。
  • 何もしなくても壊れない … サイトの表示は残ります。止まるのは新着の取り込みだけ、を目標にしています。

くわしい段取りは GitHub の Issue #493 にあります。手伝ってもいいよ、という方は Discord か Issue で声をかけてください。

コードやデータは使ってもいいですか？

どうぞ。入口と使い方のルールを公開しているものにまとめています。回の題名・概要欄・音声は朝日新聞社など各権利者のものなので、ルールの対象外です。
