全体のこと

田・蔵・宇宙・仕分けは、それぞれ何ですか？

まとめて「朝リスの輪」と呼んでいる、朝日新聞ポッドキャストを楽しむための場所です。

  • 朝リスの田（開く）… 入口です。プレイリストやおすすめなど、聴くきっかけが集まっています。
  • 朝ポキの蔵（開く）… これまでの全回の書庫です。題名や出演者で探して、聴く先へ飛べます。
  • 朝ポキの宇宙（開く）… 回を星にして、分類・言葉・時間・地図で眺める場所です。
  • みんなで仕分け（開く）… 回の分類を、朝リスのみんなで考える場所です。
分類はだれが決めているのですか？

今の分類は、AI（Claude）が題名・概要欄などの手がかりから付けた試作です。人が確かめた回は、人の判断を優先しています。

分類の分け方や名前そのものも、まだ決まったものではありません。みんなの見立てや意見で、これから育てていきたいと思っています。

宇宙の見かた

「保留」の回とは何ですか？

AIが分類しようとしたものの、手がかりが弱くて決めきれなかった回です。分類のどこにも置かず、「保留」としてまとめています。

こうした回こそ、聴いた人の見立てが頼りです。みんなで仕分けで、近いと思う分類を選んでもらえるとうれしいです。

1つの回が二つの分野に入っていることがあります。星は2つあるのですか？

いいえ、星はどの回も1つだけです。いちばん近い分類（主分類）の集まりの中に置いています。

ほかの分野の話題にも触れている回は、回の画面に「この回は『〇〇』の話題にも触れています」と文字で出ます。そちらの分野には星も線もありません。

回を選ぶと出てくる線は何ですか？

その回と関係のある回へ引いた線です。関係があるとみなす根拠は、次の3つだけです。

  • 金色の線 … 同じ記事を紹介している回
  • 青っぽい線 … 同じ出演者が出ている回、または共通の言葉がある回

関係のある回が別の分野にあると、線はそちらまで伸びます。分野どうしをつないでいる線ではありません。くわしい根拠は、回の画面の「関連する回（根拠つき）」に出ています。

緑色の点や線は何ですか？

点（星）の色は分類の色です。20の分類にそれぞれ色があり、緑系は「暮らし・生活」「動物・自然」「環境・気候」「健康・医療」「福祉・介護」です。

「言葉」の表示で言葉を選ぶと、青緑の線と ◆ が出ることがあります。◆ はその言葉が見出しに入った朝日新聞の記事で、線はその記事を紹介した回へつながっています。

分類のページにある色の帯は何ですか？

その分類に入っている回が、だれが・どれくらいの手がかりで分けたかの内訳です。色ごとに、回数の割合だけの長さになっています。

  • 緑 … 人が確かめた回
  • 青 … AIが「手がかりが十分」と見た回（確度 高）
  • 黄 … 手がかりがそこそこの回（確度 中）
  • 赤 … 手がかりが少ない回（確度 低）。ほかの分類のほうが近いかもしれません

色は「正しさ」の印ではありません。人の見立てもAIの判断も、どちらもまちがえることがあります。「この回はちがうかも」と思ったら、みんなで仕分けから見立てを送ってください。

みんなで仕分け

何人でも参加できますか？ 選んだ分類はどうなりますか？

だれでも、登録なしで参加できます。聴いた回・気になった回だけで大丈夫です。

  • 選んだ分類は、1人目から宇宙のその回に「みんなの見立て」として表れます。
  • 自分の1票はその端末ですぐに、ほかの人の分は30分ほどで反映されます。
  • 3人以上の見立てがそろって、3分の2が同じ分類なら「みんなの分類（候補）」として目立たせます。
  • 同じ回は何度でも選び直せます。数えるのは最後の1回です。
AIがもう分類した回に、ちがう意見を送れますか？

送れます。宇宙で回を開くと「この分類、ちがうかも？ 見立てを送る →」という入口があります。そこから、いまの分類を見たうえで選べます。

「ひとこと」やニックネームは公開されますか？

公開されません。この場をよくする参考にだけ使います。公開されるのは、回ごとの分類の票の数だけです。

分類の分け方や名前を提案したいです

大歓迎です。朝ポキ Discord で聞かせてください。仕分けの「ひとこと」欄に書いてもらうこともできます。

蔵書（蔵）

蔵書は、いくつも作れますか？

いまは1つの端末（ブラウザ）に1つだけです。蔵書はその端末の中にだけ保存され、サーバーには残りません。

別の蔵書を作りたいときは、「この端末から一覧を消す」で空にしてから、新しく回を入れていきます。ほかの端末やブラウザでは、それぞれ別の蔵書になります。

「URLで人に渡す」で作ったURLは、あとで蔵書を変えると変わりますか？

変わりません。URLには、作ったときの回の番号・タイトル・説明がそのまま書き込まれます。

  • あとで蔵書を作り直してURLを作ると、別のURL（別の蔵書）になります。
  • 前に渡したURLは、前の中身のまま見られます。サーバーに保存しないので、取り消すことはできません。渡す相手を選んでください。
  • URLに入るのは回の番号・タイトル・説明だけです。お名前や端末の情報は入りません。
人から受け取った蔵書を、自分の蔵書にできますか？

できます。共有URLを開くと出てくる「この蔵書をわたしの蔵書に入れる」を押すと、その回が自分の蔵書に加わります。

聴くリンク

聴くリンクはどんな順番で並んでいますか？

どの回も「朝日新聞 公式ページ → Spotify → Apple Podcasts → そのほか（Amazon Music・LISTEN など）」の順にそろえています。
