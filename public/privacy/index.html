プライバシーについて

朝リスの輪（このサイトと、その運営に使う自動化の仕組み）での情報の扱いを説明します。

このサイト

見るだけなら、会員登録もログインもいりません。集めた情報を第三者に売ったり渡したりすることはありません。

送ってもらうもの（投稿・投票したときだけ）

  • プレイリスト・番組の投稿（田） … URL、名前、お名前・ハンドルネーム、おすすめのひとこと。お名前・ハンドルネームは「by ○○」としてサイトに表示します。本名ではなく、表示されてよい名前で送ってください。
  • プレイリストの自動更新の申し込み（田） … Spotify の共同編集の招待URLと、どんな回を入れたいかのメモ。招待URLは公開しません。
  • みんなで星読みの投票 … 選んだ分類と、任意のニックネーム・ひとこと。ニックネームとひとことは公開しません。票の数だけを集計して公開します。

送られた内容は、運営者の Google スプレッドシートに保存し、サイトの運営にだけ使います。消してほしいときは、朝ポキ Discord で運営者（ネジート）に声をかけてください。

この端末（ブラウザ）だけに残るもの

「聴いた」の♡、蔵の「本棚」、宇宙の「保留の回を仕分ける」の答えは、あなたのブラウザの中だけに保存し、どこにも送りません。

アクセスの集計

どのページがどれくらい見られているかを知るために、Cloudflare Web Analytics を使っています。Cookie を使わず、個人を特定しない集計です。

田・蔵・宇宙・星読み・FAQ など、すべてのページで数えています。運営者が自分の端末で開いた分は数えないようにしています（その端末のブラウザにだけ「数えない」印を残します）。

GAS配達係（朝リスの輪 GAS配達係）

運営者が自分の Google Apps Script を更新するための内部ツールです。公開されている GitHub のコードを読み、運営者自身のスクリプトに反映するためだけに Google のアクセス許可を使います。運営者以外の利用者のデータを読んだり保存したりすることはありません。

このサイトについて

朝リスの輪（田、蔵、宇宙）は、朝日新聞ポッドキャストを聴くリスナー『朝リス🐿️』が、見て聞いて、書いて動かして話したりしてみんなで育むコミュニティサイトです。膨大な番組と、それを毎日届けつづける朝ポキの発信力に、敬意を表して。
