朝リスの輪
田蔵宇宙星読みよくある質問

公開しているもの

朝リスの輪は、コードもデータも開いた形で置いています。だれが続きを引き継いでも、どこへでも持っていけるように。

使い方のルール

  • コード … MIT ライセンス。自由に使えます。著作権表示だけ残してください。
  • 朝リスの輪が作ったデータ（EP-ID・分類・星の位置・言葉の星座・関連回・配信先リンクの対応表・星読みの票数）… CC BY 4.0。「朝リスの輪」と書けば自由に使えます。
  • 対象外 … 回の題名・概要欄・音声・関連記事は、朝日新聞社など各権利者のものです。聴くときは公式の配信先へどうぞ。

データの入口

どれも GitHub Pages に置いた JSON ファイルです。登録も鍵もいりません。毎朝、新着の取り込みのあとに更新されます。

  • 蔵（全回の書庫） … /library/data/manifest.json が目次です。
    • search/lite.json … 全回の一覧（EP-ID・番組・日時・題名）
    • search/text-*.json … 検索用の概要欄の文章（対象外の文章を含みます）
    • details/*.json … 回ごとの詳細（出演者・長さ・配信先リンク・関連記事）
  • 宇宙（星図） … /uchu/data/manifest.json が目次です。core.json（回・分類・形式）、extra.json（言葉）、rel.json（関連回）、geo-japan.json・geo-world.json（地図）。
  • GAS（自動処理）のコード … /gas/bundle.json。Google Apps Script の全ファイルを1つにまとめたものです。

例：https://neyito96.github.io/asarisunowa/library/data/manifest.json

コード

すべて GitHub にあります。意見・開発のアイデア・メモは Issue へ（よくある質問も見てください）。

朝リスの輪（田、蔵、宇宙）は、朝日新聞ポッドキャストを聴くリスナー『朝リス🐿️』が、見て聞いて、書いて動かして話したりしてみんなで育むコミュニティサイトです。膨大な番組と、それを毎日届けつづける朝ポキの発信力に、敬意を表して。
