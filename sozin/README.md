# SOZIN | 参考価格シミュレーター（公開試作）

創人デザインシステム株式会社・SOZIN Ballet de’ Arteの参考価格ページを基にした独立Webデモです。

## 動かし方
`index.html` をブラウザで開いてください。JavaScriptは `assets/js/app.js` に分離。ビルド処理・外部JavaScriptライブラリ・サーバー不要です。

## 構成
```
sozin/
  index.html           # HTMLと暫定CSS（単体閲覧しやすい）
  assets/js/app.js     # 料金定義と操作処理
  README.md            # 本書
```
将来はCSSを `assets/css/style.css` へ分離可能です。ファイル参照は相対パスで、別GitHubリポジトリや他のホスティング先へフォルダごと移せます。

## 料金出典・制限
- 出典: https://www.sozindesign.com/price （2026年11月12日参照）
- 掲載価格がテキストで確認できたPDF、デジタルブック、ポスター、バナー、印刷物セットのデジタル納品のみ計算。
- 紙プログラム、チケット、チラシ等は料金情報の確認待ちにつき「要お見積もり」。
- ポスター・バナーは印刷プログラムと同デザインでのセット前提。
- 送料・特殊仕様等を含まない税込参考価格。正式な料金はSOZINが確認。
- **社長による価格・表記承認前の実験ページ**。注文、決済、顧客情報保存は不可。
- 顧客写真、氏名、決済情報、API鍵などを公開GitHubリポジトリに保存しない。

## 移転手順
1. `sozin/` 内のファイルを新しいサーバーの公開ディレクトリへ丸ごとコピー。
2. `index.html` をルートに配置すれば `https://example.com/`、サブディレクトリなら `https://example.com/sozin/`。
3. 実装確認後、公式サイトのリンクを切り替える。既存のWixサイトやDNSは変更しない。
