# 朝リスの宇宙 — 話題の地層 V0.1

2026-10-22: Mac（127.0.0.1:5173）で Observable Plot の積み重ね面グラフが表示されたことをユーザーのスクリーンショットで確認。

## 記録対象
- `index.html`: 政治・AIの2020–2026年の**架空データ**による最初の可視化
- 背景は濃紺、Observable Plot の `Plot.areaY` + `Plot.stackY`
- 元のMac上の試作品を参照してGitHub用に再現したコード。Macのファイルそのものを取得したわけではない

## ローカル実行
Node.js と npm が必要。**このディレクトリ内で**以下を実行する。

```sh
npm init -y
npm install @observablehq/plot vite
npx vite --host 127.0.0.1
```

表示されたローカルURLをブラウザで開く。依存関係の安全性は `npm audit` で確認する。
